# Coordination plan — compile stage (P7)

- **Scope:** implement `design-compile-stage` (`docs/design/compile-stage.md`) for `spec-compile-stage`.
- **Coordinator:** this session (Owner + Coordinator seats, S2 shape: one harness, native fleet). **Sub-Agents:** one per track, `python-developer` persona, each in its own worktree created by the coordinator.
- **Multiplier stated:** two tracks plus a coordinator is roughly **3× the tokens of one session** (GO6's orchestrator-worker shape reports ~15× for wide fan-outs; this is narrow). Paid for **genuine independence** (disjoint authored paths, the CLI contract fixed in the design) and **context hygiene** (A writes ~600 lines of new Python; B performs surgery inside the 1,300-line `audit-log.py` — neither context should carry the other).
- **Date:** 2026-09-19 · **Tier:** T2 · **Fan-out cap:** 2 (the coordinator); 0 per track.
