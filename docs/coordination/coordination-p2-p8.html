### Fixed contracts (GO5: no decision edge between tracks)

Mail store (P4 writes, P6 reads; both build to this, P6 with a fixture until the join): .agents/mail/<session>.jsonl, one JSON object per line, UTF-8, newline="\n", append-only: {"id": "<ULID>", "ts": "<ISO-8601 UTC>", "from": "<session>", "to": "<session>|*", "kind": "<kind>", "body": "<text ≤ 4 KiB>", "ref": "<path|audit id|null>", "ack": null}. Kinds: delegate · blocked · unblocked · kick · decision-request · ruling · done · ack · nack · note. An ack is a new line {"kind": "ack", "ref": "<id>"}, never an in-place edit. Ledger twin: every kind except note and ack/nack is dual-written to the coord ledger .agents/log/<session>.jsonl as {"type": "mail", "mail_id": "<id>", "kind": …, "from": …, "to": …, "ref": …} (no body). Doorbell contract: a doorbell carries {"count": <n>, "pointer": "<newest mail id>"} and never a body. Board read model: the union of all .agents/mail/*.jsonl and the ledger's type: mail records, one row per mail id (who → whom · kind · ref · age · acked?), never a store; an empty corpus renders NOT CHECKED. coord board post --to <session|*> "<text>" appends a note (or a ruling with --kind ruling --ref DR-n) through the same writer (P6 imports P4's append_mail() by path; a fixture writer until the join). Constants (from Claude Code's shipped design): 50 queued, 100 held, 5-minute doorbell expiry.

Dispatch (P4): coord-mail.py dispatch --harness claude-code|codex|copilot|grok|agy --brief <file> --deadline <s> --fallback <text> [--worktree <path>] runs the harness's headless CLI under bounded_process.py with an --agent-run span, records HARNESS_STATUS per harness/version/date (verified · observed-only · unsupported — nothing not executed on this machine may read verified), refuses a dispatch without a budget or deadline, and renders unsupported for a channel not executed here.

The one crossing, resolved by ownership: P8's "consuming skills stop on an unanswered decision request" touches execute-with-coordination and prepare-for-coordination, which P2 owns. Resolution: P2 inserts the sentence P8 fixes here, verbatim, at each skill's dispatch step: *"Before dispatch, refuse a compiled prompt whose dispatchable is false or whose text still carries an unanswered DR-n line — stop with decision request unanswered: DR-n (CO-S0)."* P8 owns the same sentence in optimize-graph. Shared guards (GO14a): the three portability lints (repo root, recursive, allowlist machine-path-ok) and context-budget.py skills --gate (root pack/commands, ceiling 5,000 tokens; every SKILL.md P8 edits must stay under its recorded baseline + 2% or the addition is a citation, not a paragraph); jointly satisfiable — each track adds one sentence per skill at most.
