# AI-Forward GitHub Pages handbook — reviewable build

Open [`github-pages-handbook.html`](./github-pages-handbook.html) over `file://`. It is
generated byte-for-byte with `docs/portal/index.html` by `tools/build-handbook.py`, so
the review artifact cannot present a design that the public Pages surface does not use.

## Direction

The reader is a capable engineer who arrives curious but cautious about agentic work.
The job is to orient, choose a workflow, and start one bounded task. The retained
archetype is a reading-first content portal: serial prose for learning, parallel search
and navigation for discovery.

The qualities are **calm, exact, human**; the opposites are ornamental, vague, and
corporate. MDN Learn contributes the structured learning path; Django contributes the
clear separation between introductory, topic, and reference material. Type creates
editorial landmarks, rose marks action and position, and warm layered neutrals group
the reading surface without turning every section into a card.

## Relationship diagrams

Three diagrams earn visual treatment because each carries a relationship that is
harder to scan as prose alone:

- a five-step path from intent to a reviewable change;
- a four-step loop showing how project knowledge compounds;
- a branch showing the shared coordination contract, two independent tracks, and the
  joined proof.

Each is a labelled `figure` backed by an ordered list. Connectors are decorative; step
labels, headings, and explanations carry the meaning. On narrow screens the diagrams
become one vertical list.

## Review harness

The accepted reader contract keeps review chrome out of the shipped page. The harness
is therefore the repository's Playwright fixture: it renders newcomer and reference
routes at desktop and mobile sizes, light and dark schemes, reduced motion, no-results,
unknown-route, corrupt-data, hostile-content, and overflow states in Chromium, Firefox,
and WebKit. The test uses the same generated file as this artifact.

## Trigger map

- UI-T1: excluded — this is not an expert quantitative workbench.
- UI-T2: excluded — there is no generated imagery, persona, or motion.
- UI-T3: excluded — the page documents AI workflows but does not front a model.
- UI-T4: excluded — this is static web, not a native client.
- The unconditional UI, craft, accessibility, specification, and deterministic-control
  floors apply.
